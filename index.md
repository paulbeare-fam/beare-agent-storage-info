# Beare Agent Storage

Beare Agent Storage is a private household tool for storing generated project documents and encrypted recovery backups in an authorised Google Drive account.

It is operated by Paul Beare for household use and is not offered as a public service. The agent portal remains private. This information page provides no access to documents, backups or the portal.

The Google connection requests the **drive.file** permission. It works with files created by the application or explicitly made available to it, rather than requesting access to the account's entire Drive.
